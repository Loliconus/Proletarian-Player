# Security Policy

## Supported Versions

Поддерживается актуальная ветка `main` и последний релиз.

## Reporting a Vulnerability

Если вы нашли уязвимость:
1. Не публикуйте детали публично до исправления.
2. Отправьте отчёт на: <SECURITY_EMAIL>

Желаемые данные:
- шаги воспроизведения
- ожидаемое/фактическое поведение
- версия браузера и ОС
- логи консоли (если есть)
