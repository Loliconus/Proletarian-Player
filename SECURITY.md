# Security Policy — Proletarian Player

Дата редакции: 2026-05-31

---

## Поддерживаемые версии

На момент публикации проекта отдельные ветки поддержки не выделяются.

Поддерживается актуальное состояние ветки:

- `main`

Публичные релизы могут отсутствовать.

---

## Сообщение о проблемах безопасности

Отдельный конфиденциальный канал (почта/мессенджер) для сообщений об уязвимостях отсутствует.

Если проект размещён на GitHub, используйте (в порядке предпочтения):

1) **Security advisories / Report a vulnerability** (если в репозитории доступно) — предпочтительно для приватного обмена деталями.
2) **Issues** — если приватный отчёт недоступен (пожалуйста, без публикации полного PoC).
3) **Discussions** — для общих вопросов модели угроз и безопасного поведения.

### Что приложить к отчёту

Рекомендуется указать:

- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- версию браузера;
- операционную систему;
- сообщения консоли браузера (если имеются);
- примечания о том, требуется ли взаимодействие с локальными файлами/субтитрами.

### Публикация PoC

Если проблема может представлять риск для пользователей, желательно:

- сначала описать проблему без подробного PoC;
- дождаться подтверждения/фикса или согласовать формат PoC, который не упрощает эксплуатацию.

---

## Модель безопасности

Proletarian Player работает локально и использует минимальный набор разрешений браузера.

Текущие разрешения:

- `storage`

Проект не использует:

- удалённые скрипты;
- удалённый исполняемый код;
- серверную инфраструктуру;
- системы телеметрии;
- рекламные платформы.

---

## Ограничения безопасности

Воспроизведение мультимедиа выполняется средствами браузера через HTML5 Video.

Безопасность декодирования видео зависит от:

- браузера;
- операционной системы;
- используемых браузером кодеков и мультимедийных компонентов.

Проект не содержит собственного движка декодирования видео.
