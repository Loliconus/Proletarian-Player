## 1. Введение

**Proletarian Player** — локальный видеоплеер в форме расширения Chromium‑совместимых браузеров (Manifest V3), предназначенный для воспроизведения локальных видеофайлов, работы с субтитрами и сохранения прогресса просмотра.

Краткая характеристика области применения:

- персональное использование (дом, учёба, рабочее место);
- просмотр материалов без подключения к сети;
- просмотр курсов, лекций, архивов, записей.

## 2. Основания для разработки

Основание: инициативная разработка.  
Тема: «Локальный видеоплеер без сетевых функций».

---

## 3. Назначение разработки

### 3.1. Функциональное назначение

Программа должна обеспечивать:

- воспроизведение локальных видеофайлов в отдельной вкладке браузера;
- формирование очереди воспроизведения (файл/папка/перетаскивание);
- управление воспроизведением: пауза, перемотка, скорость, громкость;
- режимы отображения (Fit/Fill/Stretch), полноэкранный режим, PiP (если поддерживается браузером);
- работу с субтитрами: загрузка, включение/выключение, синхронизация (сдвиг);
- сохранение прогресса просмотра (SmartResume) локально.

### 3.2. Эксплуатационное назначение

Использование конечным пользователем без специальных знаний. Управление — мышью и горячими клавишами.

---

## 4. Требования к программе (программному изделию)

### 4.1. Требования к функциональным характеристикам

Программа должна:

1) **Запускаться** из интерфейса расширения (popup) и открываться в отдельной вкладке браузера.

2) **Работать с источниками файлов**:
- выбор отдельных файлов через системный диалог браузера;
- выбор папки через системный диалог браузера (при наличии File System Access API);
- Drag & Drop файлов и папок (если браузер предоставляет необходимые объекты).

3) **Формировать очередь**:
- фильтровать файлы по расширениям (видео/субтитры);
- сортировать очередь “по смыслу” имени файла (сезон/серия/эпизод, при возможности распознавания);
- обеспечивать навигацию по очереди: следующий/предыдущий, отображение списка.

4) **Управлять воспроизведением**:
- play/pause;
- перемотка шагами;
- изменение громкости и выключение звука;
- изменение скорости, сброс скорости к 1.0×.

5) **Обеспечивать функции отображения**:
- Fit/Fill/Stretch;
- полноэкранный режим (если доступен);
- Picture‑in‑Picture (если доступен);
- масштабирование/панорамирование (zoom/pan).

6) **Субтитры**:
- поддержка форматов: VTT, SRT, ASS/SSA (с конвертацией в VTT для воспроизведения в браузере);
- включение/выключение субтитров;
- сдвиг субтитров во времени.

7) **SmartResume**:
- сохранять позицию просмотра локально;
- при повторном открытии того же файла предлагать продолжить просмотр (в пределах допустимого диапазона прогресса).

8) **Дополнительные функции**:
- снимок кадра в PNG;
- экранная информация о файле (OSD/информационный слой);
- A‑B loop (зацикливание фрагмента).

### 4.2. Требования к надёжности

Программа должна:

- корректно обрабатывать неподдерживаемые браузером форматы (ошибка воспроизведения не должна приводить к зависанию интерфейса);
- корректно обрабатывать отмену диалогов выбора файлов/папок (ошибка AbortError не должна приводить к падению);
- освобождать временные ресурсы (например, Blob URL) при переключении элементов очереди/удалении из очереди.

### 4.3. Условия эксплуатации

- Браузер: Chromium‑совместимый с поддержкой Manifest V3.
- ОС: зависит от поддерживаемых браузером платформ.
- Работа без сети допускается и является штатной.

### 4.4. Требования к составу и параметрам технических средств

- ПК/ноутбук, обеспечивающий работу современного Chromium‑браузера;
- устройства вывода аудио/видео — по конфигурации пользователя.

### 4.5. Требования к информационной и программной совместимости

- Декодирование выполняется средствами браузера (HTML5 Video), поэтому поддержка контейнеров/кодеков определяется браузером и платформой.
- Данные состояния и прогресса должны храниться локально (IndexedDB/localStorage/chrome.storage.local).
- Расширение должно быть совместимо с Manifest V3.

### 4.6. Требования к маркировке и упаковке

- Поставка: каталог расширения (unpacked) и/или архив (zip) для распространения.
- Наличие иконок 16/48/128.

### 4.7. Требования к транспортированию и хранению

- Хранение исходных текстов и документации — в репозитории.
- Публикация релизов допускается тегами/архивами (при необходимости).

### 4.8. Специальные требования

- Минимизация разрешений (permissions). Разрешения расширения должны добавляться только при обоснованной необходимости.
- Отсутствие сетевых запросов и удалённых скриптов в штатном режиме.
- Не использовать разрешения, позволяющие читать содержимое вкладок/историю/URL, если задача решаема без них.

## Приложение. Термины и сокращения

- MV3 — Manifest V3 (манифест расширений Chromium).
- HTML5 Video — воспроизведение через элемент `<video>`.
- File System Access API — системные диалоги выбора файлов/папок (если поддерживается браузером).
- SmartResume — локальное сохранение прогресса и предложение продолжить просмотр.
- PiP — Picture‑in‑Picture.
- OSD — On‑Screen Display (экранная информация/индикаторы поверх видео).
