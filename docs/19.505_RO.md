# РУКОВОДСТВО ОПЕРАТОРА
## «Proletarian Player»
Обозначение: PP-RO-19.505
Версия: 2.0.0

---

## 1. Назначение программы

Proletarian Player предназначен для воспроизведения локальных видеофайлов
и управления просмотром (очередь, субтитры, скорость, зум, режимы экрана).

---

## 2. Условия выполнения программы

- Установлен Chromium-браузер с поддержкой расширений MV3.
- Расширение установлено (unpacked или из магазина).
- Для выбора файлов/папок пользователь предоставляет доступ через системный диалог.

---

## 3. Выполнение программы

### 3.1 Запуск
1) Нажать на иконку расширения.
2) Выбрать:
   - “Открыть плеер” — открыть пустой плеер (drop-зона).
   - “Открыть файл” — открыть диалог выбора видео.
   - “Открыть папку” — открыть диалог выбора директории.

### 3.2 Управление воспроизведением
- Play/Pause: Space
- Перемотка: стрелки
- Громкость: ↑/↓, mute: M
- Скорость: [ / ]
- Fullscreen: F
- PiP: P

### 3.3 Очередь
- Открыть/закрыть: Q
- Следующий/предыдущий: N / B

### 3.4 Субтитры
- Вкл/выкл: C
- Загрузить файл: Ctrl+L
- Сдвиг: через панель настроек (±100/±500 мс)

---

## 4. Сообщения оператору

Примеры:
- “⚠ Формат не поддерживается” — файл не может быть декодирован браузером.
- “⚠ Видеофайлы не найдены” — выбранная папка не содержит распознанных видео.
- “💬 Субтитры: …” — субтитры загружены/изменён сдвиг.
