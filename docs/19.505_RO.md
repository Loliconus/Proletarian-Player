# РУКОВОДСТВО ОПЕРАТОРА
## «Proletarian Player»

Обозначение: **PP-RO-19.505**  
Версия: **1.0.0**  
Дата редакции: **2026-05-31**  
Разработчик: **RedSynthesis**

> Документ оформлен в свободной форме по мотивам ЕСПД (ГОСТ 19).  
> “Оператор” в контексте расширения — пользователь, управляющий программой.

---

## 1. Назначение программы

Proletarian Player предназначен для воспроизведения локальных видеофайлов и управления просмотром:

- очередь, навигация по файлам;
- субтитры, синхронизация (сдвиг);
- скорость, громкость, mute;
- zoom/pan, режимы Fit/Fill/Stretch;
- полноэкранный режим, PiP (если доступно);
- SmartResume (продолжение просмотра).

---

## 2. Условия выполнения программы

Необходимо:

- Chromium‑совместимый браузер с поддержкой расширений Manifest V3;
- установленное расширение (unpacked или магазин);
- для выбора файлов/папок пользователь предоставляет доступ через системные диалоги браузера;
- для воспроизведения конкретного файла браузер должен поддерживать его декодирование (кодеки/контейнер).

---

## 3. Выполнение программы

### 3.1. Установка (режим разработки)

1. Открыть: `chrome://extensions`
2. Включить: **Developer mode**
3. Нажать: **Load unpacked**
4. Выбрать каталог проекта (корень расширения)

### 3.2. Запуск

1) Нажать на иконку расширения.  
2) Выбрать:

- “Открыть плеер” — открыть вкладку плеера (drop‑зона);
- “Открыть файл” — открыть диалог выбора видео/субтитров;
- “Открыть папку” — открыть диалог выбора директории (если поддерживается).

Плеер открывается в отдельной вкладке браузера.

### 3.3. Открытие файлов и формирование очереди

Варианты:

- Открыть файл — выбрать один или несколько файлов.
- Открыть папку — выбрать директорию; плеер соберёт видео и субтитры (с ограничением глубины обхода).
- Drag & Drop — перетащить файлы/папку в окно плеера.

После формирования очереди воспроизведение запускается автоматически, если очередь была пустой.

### 3.4. Управление очередью

- `Q` — открыть/закрыть панель очереди
- `N` — следующий файл
- `B` — предыдущий файл
- Shuffle/Loop доступны из панели очереди (кнопки интерфейса)

### 3.5. Управление воспроизведением

- `Space` / `K` — воспроизведение / пауза
- `←` / `→` — ±5 секунд
- `Shift + ←` / `Shift + →` — ±30 секунд
- `Ctrl + ←` / `Ctrl + →` — ±90 секунд
- `,` / `.` — покадровая перемотка (≈ 1/30 секунды)
- `Home` — в начало
- `End` — в конец
- `1..9` — переход на 10%..90% длительности

### 3.6. Громкость и скорость

Громкость:

- `↑ / ↓` — изменить громкость
- `Shift + ↑ / ↓` — быстро изменить громкость
- `M` — mute

Скорость:

- `[` — медленнее
- `]` — быстрее
- `\` — сброс к 1.00×

Колесо мыши:

- без `Ctrl` — громкость
- с `Ctrl` — масштаб (zoom)

### 3.7. Экран и отображение

- `F` — полноэкранный режим
- `P` — Picture‑in‑Picture (если поддерживается)
- `W` — Fit / Fill / Stretch

### 3.8. Субтитры

- `L` — открыть файл субтитров
- `Ctrl + L` — открыть файл субтитров (альтернативно)
- `C` — включить/выключить субтитры

Сдвиг субтитров выполняется через панель настроек (кнопки ±100/±500 мс и сброс).

### 3.9. Zoom / Pan

- `+` или `=` — увеличить масштаб
- `-` — уменьшить масштаб
- `Ctrl + 0` — сброс масштаба

При увеличенном масштабе доступно панорамирование (перемещение кадра) мышью.

### 3.10. Информация и инструменты

- `I` — экранная информация о файле (OSD)
- `T` — постоянное отображение таймера
- `S` — снимок кадра (PNG)

### 3.11. A‑B loop

- `A` — установить точку A
- `Z` — установить точку B
- `Ctrl + A` — сбросить цикл

---

## 4. Сообщения оператору

Программа выводит уведомления (OSD/тосты) в типовых ситуациях:

- ошибки открытия файлов/папок (кроме штатной отмены диалога);
- отсутствие видеофайлов в выбранной папке;
- ошибки декодирования/воспроизведения;
- состояние функций (loop, shuffle, субтитры, сдвиг, PiP недоступен и т.п.).

---

## 5. Действия при нештатных ситуациях

- Если файл “не воспроизводится”: проверить, поддерживает ли браузер декодирование этого файла/кодека.
- Если “Открыть папку” недоступно или не работает: браузер может не поддерживать File System Access API.
- Если субтитры не отображаются: проверить формат (SRT/VTT/ASS/SSA), кодировку текста и наличие тайминга.

---

## 6. Завершение работы

Для завершения достаточно закрыть вкладку плеера.  
Данные прогресса и настроек сохраняются локально до удаления расширения или очистки данных.
