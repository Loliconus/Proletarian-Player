# ОПИСАНИЕ ПРОГРАММЫ
## «Proletarian Player»
Обозначение: PP-OP-19.402
Версия: 2.0.0

---

## 1. Общие сведения

Наименование: Proletarian Player.  
Форма поставки: расширение Chromium (Manifest V3).  
ПО для функционирования: Chromium-браузер с поддержкой расширений MV3.  
Языки реализации: JavaScript, HTML, CSS.

---

## 2. Функциональное назначение

Класс задач:
- локальное воспроизведение видеоматериалов;
- управление очередью и параметрами воспроизведения;
- субтитры и синхронизация;
- сохранение прогресса просмотра.

Ограничения:
- поддержка контейнеров/кодеков зависит от браузера и ОС;
- “открыть папку” зависит от поддержки Directory Picker.

---

## 3. Описание логической структуры

### 3.1 Структура модулей
- popup (UI запуска)
- background (service worker)
- player (основной UI и состояние)

### 3.2 Связи между частями
- popup отправляет сообщение `pp.open` в background
- background открывает/фокусирует вкладку player
- player работает автономно, сохраняя прогресс локально

### 3.3 Данные состояния (упрощённо)
- очередь: массив элементов (File + метаданные)
- активный индекс очереди
- позиция воспроизведения
- настройки (громкость/скорость/режим aspect)
- состояние субтитров, A-B loop, zoom/pan

---

## 4. Используемые технические средства

- ПК/ноутбук с современным Chromium-браузером.
- Устройства вывода аудио/видео по конфигурации пользователя.

---

## 5. Вызов и загрузка

Способ вызова:
- из popup расширения (кнопки “Открыть плеер/файл/папку”).

Точка входа:
- `player/player.html`, инициализация в `player/js/player.js`.

---

## 6. Входные данные

- локальные видеофайлы пользователя;
- локальные файлы субтитров пользователя.

Организация:
- выбираются пользователем вручную, либо перетаскиванием.

---

## 7. Выходные данные

- видео/аудио поток на устройство вывода;
- локальные записи прогресса просмотра (история) и настроек.
