# ПОЯСНИТЕЛЬНАЯ ЗАПИСКА
## «Proletarian Player»
Обозначение: PP-PZ-19.404
Версия: 2.0.0

---

## 1. Введение

Наименование программы: Proletarian Player.
Основание разработки: инициативная разработка по теме локального воспроизведения
видеоматериалов без сетевых функций.

(Исторический материализм в быту таков: инструмент должен служить практике,
а не превращать практику в придаток инструмента.)

---

## 2. Назначение и область применения

Назначение:
- воспроизведение локальных видеофайлов в интерфейсе браузера;
- управление воспроизведением, очередью и субтитрами;
- хранение прогресса просмотра локально.

Область применения:
- обучение, самообразование, просмотр архивов;
- демонстрация материалов офлайн.

---

## 3. Технические характеристики

### 3.1 Постановка задачи
Создать плеер-расширение MV3, не требующее аккаунта, сервера, сети и избыточных разрешений.

### 3.2 Описание методов и допущений
- Декодирование видео выполняет браузер (а значит, поддержка форматов зависит от ОС/кодеков).
- Доступ к файлам осуществляется через File System Access API и drag&drop.
- Хранение прогресса: IndexedDB + chrome.storage.local.

### 3.3 Описание алгоритма/функционирования
- Пользователь формирует набор файлов (файл/папка/перетаскивание).
- Очередь сортируется по “смысловому имени” (серии/сезоны/эпизоды при возможности распознавания).
- При воспроизведении периодически сохраняется позиция просмотра.
- При повторном открытии предлагается продолжить (SmartResume).

### 3.4 Организация входных/выходных данных
Вход:
- видеофайлы и файлы субтитров пользователя.

Выход:
- визуальный поток, аудиопоток;
- локальные записи прогресса просмотра.

### 3.5 Выбор средств
- Ядро: HTML5 video + JS-модули.
- Хранилища: IndexedDB/localStorage/chrome.storage.

---

## 4. Ожидаемые технико-экономические показатели

- Снижение времени на поиск позиции просмотра.
- Снижение когнитивной нагрузки (единая схема управления).
- Нулевая стоимость эксплуатации сервера (сервер отсутствует).
