# Privacy Policy — Proletarian Player

Дата редакции: 2026-05-31

---

## Кратко

Proletarian Player — локальный видеоплеер в форме расширения браузера.

Программа не использует серверную инфраструктуру, не отправляет пользовательские данные через сеть и не требует регистрации или учётной записи.

Все данные обрабатываются и хранятся локально на устройстве пользователя.

---

## Какие данные используются

### Локальные файлы

Пользователь самостоятельно выбирает:

- видеофайлы;
- файлы субтитров.

Файлы используются исключительно локально для воспроизведения и обработки субтитров и не отправляются через сеть.

---

### История просмотра (SmartResume)

Для работы функции SmartResume сохраняются:

- имя файла;
- размер файла;
- длительность;
- позиция просмотра;
- процент просмотра;
- статус просмотра;
- дата последнего просмотра.

---

### Пользовательские настройки

Для сохранения параметров интерфейса могут храниться:

- уровень громкости;
- скорость воспроизведения;
- режим отображения видео.

---

### Последний просмотр

Для отображения информации во всплывающем окне расширения сохраняется запись о последнем просмотренном файле:

- имя файла;
- длительность;
- текущая позиция;
- процент просмотра.

---

## Где хранятся данные

### IndexedDB

Используется для хранения истории просмотра и данных SmartResume.

### localStorage

Используется для хранения пользовательских настроек.

### chrome.storage.local

Используется для хранения записи о последнем просмотренном файле, отображаемой во всплывающем окне расширения.

---

## Что программа не делает

Программа:

- не собирает аналитику;
- не отслеживает действия пользователя на сайтах;
- не читает содержимое вкладок браузера;
- не передаёт данные разработчику;
- не передаёт данные третьим лицам;
- не использует рекламные сети;
- не использует системы телеметрии.

---

## Разрешения браузера

На текущий момент используется только одно разрешение:

- `storage`

Оно необходимо для хранения настроек и состояния программы.

---

## Хранение данных

Данные сохраняются локально до тех пор, пока пользователь:

- не удалит расширение;
- не очистит данные расширения;
- не очистит данные браузера.

---

## Изменения политики

При изменении принципов обработки данных данный документ может быть обновлён.

Актуальная версия публикуется вместе с исходным кодом проекта.
