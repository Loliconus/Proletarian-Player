# Privacy Policy — Proletarian Player

Дата: 2026-05-30

## Коротко

Proletarian Player — локальный видеоплеер. Он не является сервисом и не использует
удалённый сервер разработчика.

## Какие данные обрабатываются

1) **Файлы пользователя**  
Пользователь выбирает локальные видео/субтитры через системный диалог (File Picker)
или перетаскивает их в окно плеера. Эти файлы используются только для воспроизведения.

2) **Локальная история просмотра**  
Для удобства плеер сохраняет на устройстве:
- имя файла (как есть в файловой системе)
- длительность
- последнюю позицию просмотра
- процент прогресса
- дату последнего просмотра

## Что НЕ делается

- Не собираем статистику кликов.
- Не отправляем историю просмотра в сеть.
- Не читаем содержимое сайтов.
- Не продаём и не передаём данные третьим лицам.

## Где хранятся данные

- История просмотра: IndexedDB (локально).
- Настройки: localStorage (локально).
- “Последний просмотр” для окна popup: chrome.storage.local (локально).

## Срок хранения

Данные хранятся, пока пользователь не удалит расширение или не очистит данные сайта/расширения.
