# Proletarian Player

Локальный видеоплеер в форме расширения для Chromium‑совместимых браузеров.

Без излишеств. Для людей.

**Proletarian Player** предназначен для воспроизведения **локальных** видеофайлов, работы с субтитрами и сохранения прогресса просмотра.  
Программа не использует серверную инфраструктуру, не требует учётной записи и хранит данные **только на устройстве пользователя**.

Проект поддерживается открытым коллективом **RedSynthesis** — инженерным объединением, которое собирает утилиты, служащие пользователю, а не рынку.  

---

## Возможности

- Открытие отдельных файлов
- Открытие папок через системный диалог браузера *(File System Access API)*
- Drag & Drop файлов и папок
- Очередь воспроизведения
- Автоматическая сортировка серий и эпизодов по имени файла
- Перемешивание очереди *(Shuffle)*
- Повтор очереди *(Loop)*
- **SmartResume** (продолжить с места)
- Субтитры:
  - WebVTT (`.vtt`)
  - SubRip (`.srt`)
  - ASS / SSA (`.ass`, `.ssa`)
- Синхронизация субтитров (сдвиг тайминга)
- Масштабирование и панорамирование видео *(zoom/pan)*
- Режимы отображения: **Fit / Fill / Stretch**
- Picture‑in‑Picture (PiP)
- Полноэкранный режим
- Снимок кадра (PNG)
- Экранная информация о файле (OSD)
- Горячие клавиши
- A‑B Loop (зацикливание фрагмента)

## Совместимость

Проект рассчитан на Chromium‑браузеры с поддержкой:

- **Manifest V3**
- **HTML5 Video** (`<video>`)
- **File System Access API** *(для открытия файлов/папок через системные диалоги “Открыть файл/папку”)*

### Испытания

Работоспособность проверялась на:

- Яндекс.Браузер 26.4.3.894 (64-bit)

Работа в других Chromium‑браузерах предполагается, но отдельно не документировалась.

### Яндекс.Браузер (важно)

Яндекс.Браузер доверяет расширениям из Chrome Web Store или Opera Add-ons.  
Расширения, установленные “из других источников”, могут отключаться при запуске, и тогда пользователю придётся включать их вручную.

---

## Ограничения (важно)

Воспроизведение и декодирование выполняется средствами браузера (HTML5 Video).  
Поддержка контейнеров/кодеков зависит от конкретного браузера и платформы (включая доступные мультимедийные компоненты).

Плеер **не содержит собственных кодеков**. Если браузер не умеет декодировать файл, плеер не сможет его воспроизвести.

## Установка

### Установка в режиме разработки (Load unpacked)

1. Откройте: `chrome://extensions`
2. Включите: **Developer mode**
3. Нажмите: **Load unpacked**
4. Выберите каталог проекта (корень репозитория)

---

## Использование

Нажмите на значок расширения и выберите:

- **Открыть плеер**
- **Открыть файл**
- **Открыть папку**

Плеер откроется в отдельной вкладке браузера.

## Горячие клавиши

### Воспроизведение
- `Space` — воспроизведение / пауза
- `K` — воспроизведение / пауза

### Перемотка
- `← / →` — ±5 секунд
- `Shift + ← / →` — ±30 секунд
- `Ctrl + ← / →` — ±90 секунд
- `, / .` — покадровая перемотка

### Громкость
- `↑ / ↓` — изменение громкости
- `Shift + ↑ / ↓` — быстрое изменение громкости
- `M` — отключение звука

### Скорость
- `[` — уменьшить скорость
- `]` — увеличить скорость
- `\` — сброс к 1.00×

### Видео
- `F` — полноэкранный режим
- `P` — Picture‑in‑Picture
- `W` — переключение **Fit / Fill / Stretch**

### Очередь
- `Q` — показать/скрыть очередь
- `N` — следующий файл
- `B` — предыдущий файл

### Субтитры
- `C` — включить/выключить субтитры
- `L` — открыть файл субтитров
- `Ctrl + L` — открыть файл субтитров (альтернативная комбинация)

### Дополнительно
- `I` — экранная информация о файле (OSD)
- `S` — снимок кадра (PNG)
- `T` — постоянное отображение таймера

### A‑B Loop
- `A` — установить точку A
- `Z` — установить точку B
- `Ctrl + A` — сброс цикла

## Конфиденциальность

Программа работает локально.

Не выполняется:
- сбор аналитики;
- передача пользовательских данных разработчику;
- отправка истории просмотра в сеть;
- чтение содержимого сайтов и вкладок браузера.

Подробности — в `PRIVACY.md`.

## Разрешения (permissions)

- `storage` — хранение настроек и локального состояния (включая “последний просмотр” для popup)

## Архитектура проекта

- `manifest.json` — MV3‑манифест расширения
- `background/`
  - `service-worker.js` — service worker расширения (служебные события)
- `popup/`
  - UI расширения: запуск плеера/открытие файла/папки, показ “последнего просмотра”
- `player/`
  - `player.html` — основная страница плеера
  - `player.css` — стили интерфейса
  - `player/js/helpers.js` — утилиты (в т.ч. разбор имён для сортировки)
  - `player/js/storage.js` — локальные хранилища (IndexedDB/localStorage)
  - `player/js/subtitles.js` — субтитры: загрузка/конвертация/синхронизация
  - `player/js/zoom.js` — zoom/pan
  - `player/js/queue.js` — очередь воспроизведения
  - `player/js/player.js` — ядро приложения (UI/управление/горячие клавиши/SmartResume)
