# Proletarian Player

**Proletarian Player** — локальный видеоплеер в форме расширения Chromium-браузера.
Он не торгует вашим вниманием и не ведёт тайных переписей. Его предмет прост:
дать человеку средство воспроизведения **своих** файлов — как орудие труда,
а не как витрину рынка.

> Диалектика здесь бытовая: пользовательская свобода начинается там,
> где инструмент не требует лишнего и не просит лишнего.

## Возможности

- Открытие **файла** и **папки** (File System Access API)
- Drag & Drop файлов/папок
- Очередь воспроизведения, shuffle, loop
- SmartResume (продолжить с места)
- Субтитры: SRT/VTT/ASS/SSA, синхронизация
- Зум и панорамирование, Fit/Fill/Stretch
- PiP, полноэкранный режим
- Скриншот кадра (PNG)
- Инфо о файле (OSD)

## Установка (для разработки)

1. Открой `chrome://extensions`
2. Включи **Developer mode**
3. Нажми **Load unpacked**
4. Укажи папку проекта

### Яндекс.Браузер (важно)

Яндекс.Браузер доверяет расширениям из **Chrome Web Store** или **Opera Add-ons**.
Расширения, установленные “из других источников”, могут отключаться при запуске,
и тогда пользователю придётся включать их вручную на свой риск.
Для “нормальной жизни” расширения — публикуйся в магазине.

## Использование

- Нажми на иконку расширения:
  - **Открыть плеер**
  - **Открыть файл**
  - **Открыть папку**

Плеер открывается во вкладке `chrome-extension://.../player/player.html`.

## Горячие клавиши (основные)

- Space / K — play/pause
- ← / → — перемотка ±5 сек
- Shift+← / Shift+→ — ±30 сек
- Ctrl+← / Ctrl+→ — ±90 сек
- M — mute
- [ / ] — скорость
- F — fullscreen
- P — PiP
- Q — очередь
- I — инфо о файле
- S — скриншот
- A / Z — A-B loop (A — поставить A, Z — поставить B, Ctrl+A — сброс)

## Разрешения (почему их столько)

- `storage` — хранение последнего просмотра (для popup) и служебных настроек.

Принцип простой: **не просим того, что не нужно для текущих функций**.
Это соответствует практике “minimum permission”.

## Данные и приватность (коротко)

- Плеер работает локально.
- Ничего не отправляет в сеть.
- История просмотра хранится **на устройстве** пользователя.

Подробности — в `PRIVACY.md`.

## Архитектура (кратко)

- `popup/` — UI-рычаг (открыть плеер / файл / папку + “последний просмотр”)
- `background/` — service worker: открывает/фокусирует вкладку плеера
- `player/` — основная страница и модули:
  - `helpers.js` — чистые утилиты
  - `storage.js` — IndexedDB история + localStorage настройки
  - `queue.js` — очередь
  - `subtitles.js` — субтитры и синхронизация
  - `zoom.js` — зум/пан
  - `player.js` — сборка состояния и UI
